Which one is for you?

Pick the right tool

leon.music

You want your own music to feel like a streaming service, with mixes, charts, Rewind, friends and your own radio stations, for your household or friends. It's simple to run on a Windows PC.

Navidrome

You want a fast, lightweight music server that handles very large libraries, with years of polish behind it.

Jellyfin

You want one free, open-source server for movies, TV and music, with a big plugin ecosystem.

Plex

You want a polished, all-in-one media server with Plexamp, and you don't mind a Plex account or paying for some extras.

💡You don't have to choose just one. They all read the same music folder, so you can run leon.music next to any of them.
